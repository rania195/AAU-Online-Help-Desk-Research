 AAU-Online-Help-Desk-Research
 
Factors Affecting the Effectiveness of the Addis Ababa University Online Help Desk System in Resolving Students’ Service Requests

About the Project

This research examines the factors affecting the effectiveness of the Addis Ababa University Online Help Desk System in resolving students’ service requests. It focuses on factors such as ease of use, information quality, response time, communication, request follow-up, and student satisfaction.
